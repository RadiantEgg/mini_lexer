# Mini Lexer

一个使用 C 语言手写实现的小型词法分析器（Lexer）。

本项目目标是学习编译器前端中的词法分析过程：

    Source Code
        |
        v
      Lexer
        |
        v
    Token Stream

当前阶段负责：

-   字符流扫描
-   Token 生成
-   Identifier 识别
-   Number 识别
-   操作符识别
-   错误处理
-   行列记录

------------------------------------------------------------------------

# Lexer 设计

## 核心结构

当前采用指针扫描：

``` c
struct Lexer
{
    const char *source;
    const char *start;
    const char *current;

    size_t line;
    size_t column;
};
```

说明：

  |字段    |  作用 |
  |---| ---|
  |source    |输入字符流
  |start    | 当前 Token 起点
  |current   |当前扫描位置
  |line     | 行号
  |column  |  列号

------------------------------------------------------------------------

# Token 设计

Token 使用：

``` c
start + length
```

表示 lexeme，而不是复制字符串。

例如：

输入：

    hello123

Token 保存：

    start -> h
    length -> 8

优点：

-   减少 malloc/free
-   避免字符串复制
-   生命周期清晰

------------------------------------------------------------------------

# 当前支持功能

## 1、EOF

EOF 表示字符流结束。

特点：

-   length = 0
-   不保存 lexeme

------------------------------------------------------------------------

## 2、Identifier

规则：

    [A-Za-z_][A-Za-z0-9_]*

支持：

    abc
    hello123
    _value

不支持：

    123abc

------------------------------------------------------------------------

## 3、Number

当前支持整数，带一个小数点，可位于开头结尾：

    0
    123
    99999
    1.
    5.
    1.5

不支持科学计数法：

    1.23
    1e10

------------------------------------------------------------------------

## 4、单字符 Token

支持：

  |字符 |  Token|
 | ---|---|
  |\+    | PLUS
  |\-     |MINUS
  |\*     |STAR
  |/      |SLASH
  |(      |LPAREN
  |)      |RPAREN

------------------------------------------------------------------------

## 5、空白处理

支持：

-   空格
-   tab
-   换行

不会生成 Token。

------------------------------------------------------------------------

## 6、行列记录

Token 保存：

    line
    column

用于：

-   错误定位
-   Debug
-   后续语法分析

------------------------------------------------------------------------

## 7、ERROR Token

非法字符生成 ERROR：

例如：

输入：

    abc@123

输出：

    IDENTIFIER abc
    ERROR @
    NUMBER 123

Lexer 会继续扫描。

------------------------------------------------------------------------

# 当前不支持功能

## 1、多字符操作符

不支持：

    ==
    !=
    <=
    >=
    +=
    -=
    ++
    --
    &&
    ||

未来需要：

-   peek 多字符
-   操作符表

------------------------------------------------------------------------

## 2、Assignment 和 Comparison

需要区分：

    =
    ==

分别对应：

    TOKEN_ASSIGN
    TOKEN_EQUAL_EQUAL

------------------------------------------------------------------------

## 3、MACRO（宏）

当前不处理 C 预处理器：

例如：

``` c
#define MAX(a,b) ...
#ifdef DEBUG
#endif
```

原因：

宏处理通常属于 Preprocessor。

未来可以增加：

-   宏定义 Token
-   条件编译支持

------------------------------------------------------------------------

## 4、位运算符

当前不支持：

    &
    |
    ^
    ~
    <<
    >>

未来增加：

    TOKEN_AND
    TOKEN_OR
    TOKEN_XOR

------------------------------------------------------------------------



## 5、科学计数法

不支持：

    1e10
    1.5e-3

------------------------------------------------------------------------

## 6、字符串

不支持：

    "hello"

未来需要：

-   字符串结束判断
-   转义处理

例如：

    \n
    \t
    \"

------------------------------------------------------------------------

## 7、字符常量

不支持：

    'a'
    '\n'

------------------------------------------------------------------------

## 8、注释

不支持：

单行：

``` c
// comment
```

多行：

``` c
/*
 comment
*/
```

------------------------------------------------------------------------

## 8、Keyword

当前：

    if
    while
    return
    int

都会识别为：

    IDENTIFIER

未来：

增加 keyword table。

------------------------------------------------------------------------
